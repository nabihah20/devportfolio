# Nabihah Taquddin Azmy — Portfolio Website

Personal portfolio website showcasing software engineering, embedded systems, touchscreen GUIs (ESP32-S3, LVGL, SquareLine Studio), IoT telemetry platforms, and full-stack web systems.

## Tech Stack
- **Structure**: Semantic HTML5 with responsive mobile-first architecture
- **Styling**: Vanilla CSS (Obsidian Dark & Clean Executive Light themes)
- **Interactivity**: Vanilla JavaScript (Interactive tab switcher, mobile dropdown, theme toggle)
- **Assets**: Circular favicon, avatar images, and verified downloadable resume PDF
